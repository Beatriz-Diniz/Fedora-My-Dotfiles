# Fedora-My-Dotfiles
This repository contains my personal configuration files, also known as dotfiles, for Fedora 44+ with Hyprland.

The current setup is based on the Rosé Pine theme. The wallpapers used in the previews are stored inside the Rosé Pine theme directory:

```bash
home/.config/hyde/themes/Rosé Pine/wallpapers/
```

When using another Hyde theme, copy the wallpapers folder from Rosé Pine into the target theme directory so the same animated wallpapers are available there.

Example:
```bash
cp -r ~/.config/hyde/themes/"Rosé Pine"/wallpapers ~/.config/hyde/themes/"Theme Name"/
```

## Keybindings

Main modifier: `Super` / `Meta` / `Windows key`

| Shortcut | Action |
|---|---|
| `Super + T` | Open terminal |
| `Super + E` | Open file manager |
| `Super + C` | Open VS Code |
| `Super + F` | Open Brave |
| `Super + A` | Open application launcher |
| `Super + Tab` | Open window switcher |
| `Super + V` | Open clipboard history |
| `Super + Q` | Close focused window |
| `Super + W` | Toggle floating window |
| `Alt + F11` | Toggle fullscreen |
| `Super + L` | Lock screen and suspend |
| `Super + Backspace` | Open logout menu |
| `Super + 1-9` | Switch workspace |
| `Super + Shift + 1-9` | Move window to workspace |
| `Super + Ctrl + Left/Right` | Previous/next workspace |
| `Super + Left/Right/Up/Down` | Move focus |
| `Super + P` | Area screenshot |
| `Super + Ctrl + P` | Frozen area screenshot |
| `Print` | Screenshot all monitors |
| `Super + Shift + W` | Open wallpaper selector |
| `Super + Shift + T` | Open theme selector |
| `Super + Alt + Left/Right` | Previous/next wallpaper |
| `Super + Alt + G` | Toggle game mode |
